mw2coop {VERSION}: campaign co-op for Call of Duty: Modern Warfare 2 (2009), two players
https://github.com/stxlvn/mw2_coop

=== По-русски ===

Что это: кооператив на двоих для кампании MW2 (2009) в актуальной 64-битной Steam-версии.
Бета: все сцены кампании переделаны на двоих, играть можно; известные проблемы — в README.md на GitHub.

Нужно:
- Windows 10/11, MW2 (2009) в Steam (appid 10180), 64-битная сборка (обновление сентября
  2026). На другой сборке мод сам выключается и ничего не делает.
- Игра у каждого из двух игроков, и ОДИНАКОВЫЕ файлы мода у обоих (иначе рассинхрон).
- Хосту: открытый UDP-порт 28960 (проброс на роутере) или общая локальная сеть / VPN
  (Radmin VPN, ZeroTier и т. п.).

Установка (у обоих игроков):
1. Steam -> Библиотека -> Modern Warfare 2 -> Управление -> Просмотреть локальные файлы.
   Откроется папка с iw4sp.exe.
2. Скопируйте туда всё из этого архива: winmm.dll и папку mw2coop.
   (Ничего из игры не заменяется: добавляются новые файлы.)

Игра (всё в меню игры):
1. Хост: Кампания -> СЕТЕВАЯ ИГРА ВДВОЕМ. Откроется лобби с миссией, на которой вы
   остановились (или первой). "Выбор операции" меняет миссию, "Доступ" - кто может войти:
   свободный / только друзья Steam / по паролю; "Огонь по своим" - вкл или выкл.
2. Второй игрок:
   - друг по Steam: хост жмёт "Пригласить друга", друг принимает приглашение в Steam;
   - по сети (одна локальная сеть или Radmin VPN): Кампания -> ПРИСОЕДИНИТЬСЯ К ИГРЕ,
     выбрать игру в списке (или "Ввести адрес вручную..." и ввести IP хоста).
3. Оба жмут "Готов", хост жмёт "Старт".
Прогресс хранится у хоста (mw2coop\progress): у каждого прохождения своё сохранение со списком
игроков; "Продолжить" открывает прохождение вашего напарника, "Выбрать сохранение" - любое.
Не удаляйте mw2coop\player.ini: по нему вас узнают в сохранениях.

Если брандмауэр Windows не пускает второго игрока, игра сама предложит это исправить, когда
хост откроет лобби (Windows один раз спросит права администратора). Через интернет без общей
сети: роутер хоста сам откроет порт, если на нём включён UPnP; иначе нужен проброс UDP-порта
28960 или Radmin VPN. Порт меняется в mw2coop\settings.ini (у обоих одинаковый).

Удаление: удалите из папки игры winmm.dll и папку mw2coop.
(Правило брандмауэра, если его добавлял мод: "Call of Duty MW2 co-op (mw2coop)".)
Проблемы: приложите mw2coop\mw2coop.log обоих игроков.

ЭКСПЕРИМЕНТАЛЬНО: встроенный разделённый экран (две половины одного окна, один ПК)
Это пререлиз: кроме сетевой игры в нём есть режим "РАЗДЕЛЕНИЕ ЭКРАНА" для двух игроков на одном компьютере. Он новый
и может падать; для обычной игры по сети он не нужен.
Как запустить: Кампания -> РАЗДЕЛЕНИЕ ЭКРАНА. Откроется лобби с двумя карточками: Альфа (верхняя половина) и Браво
(нижняя). Каждый игрок нажимает кнопку на том устройстве, на котором будет играть: клавишу или мышь для клавиатуры и
мыши, любую кнопку геймпада (XInput) для геймпада. Backspace (клавиатура) или Back (геймпад) отменяет выбор. "Старт"
ждёт, пока выберут оба. Любой игрок может играть на любом устройстве: два геймпада или геймпад и клавиатура.
Экран режется на верхнюю и нижнюю половины; при возврате в меню режим выключается сам.
Геймпад (раскладка консоли): левый стик — движение, правый — обзор, LT — прицел, RT — огонь, A — прыжок, B — стойка
(удержание — лёжа), X — перезарядка (удержание — использовать), Y — следующее оружие, LB / RB — гранаты, LS — бег,
RS — удар ножом, Back — задачи, Start — пауза, крестовина — слоты действий. Помощь в прицеливании и вибрация как на
консоли, в подсказках кнопки геймпада вместо клавиш.
Настройки для каждого игрока (чувствительность, инверсия, помощь в прицеливании, смена стиков, тактическая раскладка,
вибрация): главное меню -> Настройки -> Управление -> Геймпад: Альфа / Геймпад: Браво. Второй игрок не управляет меню,
только ставит паузу.
Известные проблемы: геймпады проверены только имитацией; звук один на двоих (слышно с места первого игрока);
игра может не закрыться сама после выхода (закройте её в диспетчере задач). Старая 32-битная игра: архив
mw2coop-<версия>-x86.zip, клиент iw4x-sp: mw2coop-<версия>-iw4x.zip (оба экспериментальные). Если что-то не так, приложите mw2coop\mw2coop.log.

=== English ===

Two-player co-op for the MW2 (2009) campaign on the current 64-bit Steam build. Beta: every set
piece is reworked for two and it is playable; known issues are in README.md on GitHub.

Needs: Windows 10/11; MW2 (2009) on Steam (appid 10180), the 64-bit build (September 2026
update; on any other build the mod switches itself off); the game and the SAME mod files on
both PCs; for the host, UDP port 28960 reachable (port forward) or a shared LAN/VPN.

Install (both players): Steam -> Library -> Modern Warfare 2 -> Manage -> Browse local files
(the folder with iw4sp.exe). Copy everything from this archive there: winmm.dll and the
mw2coop folder. Nothing of the game is replaced.

Play (in the game's menus): the host picks Campaign -> TWO PLAYERS ONLINE; the lobby opens
on the mission where you stopped (Change Op picks another; Access sets who may join: open,
Steam friends only, or a password; Friendly fire: on or off). The partner joins through a Steam invite (Invite Friend),
or on a shared network (LAN, Radmin VPN) through Campaign -> JOIN A GAME (pick the game from
the list, or enter the host's address). Both press Ready, the host presses Start. Progress is
kept by the host (mw2coop\progress), one save per playthrough with its players: Continue opens
your partner's, Pick a save any of them. Keep mw2coop\player.ini: saves know you by it.

If Windows Firewall would keep the partner out, the game offers to fix it when the host opens
the lobby (Windows asks for administrator rights once). Over the internet without a shared
network: the host's router opens the port itself if UPnP is on; otherwise forward UDP port
28960, or use Radmin VPN. The port can be changed in mw2coop\settings.ini (the same on both PCs).

Uninstall: delete winmm.dll and the mw2coop folder from the game folder. Problems: attach mw2coop\mw2coop.log from both players.

EXPERIMENTAL: the built-in split screen (two halves of one window, one PC)
This is a pre-release: besides online co-op it has a SPLIT SCREEN mode for two players on one computer. It is new
and may crash; online play does not need it.
To start it: Campaign -> SPLIT SCREEN. The lobby opens with two cards, Alpha (the top half) and Bravo (the bottom half).
Each player presses a button on the device they will play on: a key or the mouse for keyboard and mouse, any button on
a gamepad (XInput) for a gamepad. Backspace (keyboard) or Back (gamepad) takes the choice back. Start waits until both
have chosen. Either player can play on either device; two gamepads, or one gamepad and the keyboard, both work.
The screen is cut into a top and a bottom half; the mode switches itself off when you are back in the menus.
Gamepad (the console layout): left stick move, right stick look, LT aim, RT fire, A jump, B stance (hold: prone),
X reload (hold: use), Y next weapon, LB / RB grenades, LS sprint, RS melee, Back objectives, Start pause, d-pad the
action slots. Aim assist and vibration work as on the console, and hints show the gamepad's buttons instead of keys.
Per player options (look sensitivity, inverted look, aim assist, swapped sticks, tactical layout, vibration): Options ->
Controls -> Gamepad: Alpha / Gamepad: Bravo in the main menu. The second player cannot work the menus, only pause.
Known issues: the gamepad part is tested with simulated gamepads only; one sound listener; the game may not close by itself
after quitting (end it in Task Manager). The older 32-bit game: the archive
mw2coop-<version>-x86.zip, the iw4x-sp client: mw2coop-<version>-iw4x.zip (both experimental). If something is wrong, attach mw2coop\mw2coop.log.
